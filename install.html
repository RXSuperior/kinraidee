📋 คู่มือติดตั้ง KinRaiDee

ขั้นตอนที่ 1: สร้างฐานข้อมูล

เข้าไปที่ phpMyAdmin ของ Angsila → สร้างฐานข้อมูล → นำเข้าไฟล์ database.sql

ขั้นตอนที่ 2: แก้ไขไฟล์ config.php

เปลี่ยน 3 ค่าให้ตรงกับระบบของคุณ:

$dbname = 'ชื่อฐานข้อมูล';
$username = 'ชื่อผู้ใช้';
$password = 'รหัสผ่าน';

ขั้นตอนที่ 3: อัปโหลดไฟล์ผ่าน FileZilla

อัปโหลดไฟล์ทั้งหมดไปที่:

public_html/kinraidee/

ขั้นตอนที่ 4: เปิดใช้งาน

เปิดลิงก์:

https://angsila.cs.buu.ac.th/~ชื่อผู้ใช้/kinraidee/
